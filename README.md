# Jira/Confluence Automation Toolkit

Automation assets for Jira and Confluence workflows, built with AI assistance.

## Contents

- `instructions/` contains reusable agent instructions for project tracking and reporting workflows.
- `tools/` contains command-line utilities for compound interest, risk scores, and milestone variance.
- `work/` contains module reports and MCP configuration examples.

## GitHub MCP

The VS Code MCP configuration is in `work/.vscode/mcp.json` and includes the GitHub HTTP MCP server alongside the local example servers.
