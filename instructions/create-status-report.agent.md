# Weekly Status Report Generator

Create a weekly status report using these rules:

- Output format: Markdown only.
- Use exactly these three section headings, in this order: `## Accomplishments`, `## Blockers`, and `## Next Week`.
- Put all report content under the headings as bullet points; do not write paragraphs, tables, or numbered lists.
- Keep the complete report to a maximum of 20 lines, including headings and blank lines.
- Use a professional, factual, concise tone.
- State concrete outcomes, owners, dates, metrics, and requested actions when they are available.
- If a section has no updates, write `- None reported.` under that heading.
- Do not invent missing facts; write `- Not provided.` when required information is unavailable.
- Remove fluff words and promotional language, including `very`, `really`, `just`, `great`, `exciting`, `successfully`, and `seamless`.
- Before returning the report, count its lines and shorten bullet points until it is within the 20-line limit.
